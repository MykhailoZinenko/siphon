# Алгоритм 4 — Template-based DPA (4.3.2.3)

Скрипт: `siphon/alg4_templates.py`

## Что делает

| Шаг книги | Что это |
|---|---|
| Template Step a | выбрать точки интереса (можно несколько) |
| Template Step b | построить шаблон `(μₛ, Qₛ)` для каждого значения целевого сигнала |
| Template Step c | оценить гипотезы по правдоподобию (ур. 4.33), победитель — максимум |

Различитель здесь **не корреляция**, а вероятность: «насколько правдоподобна
наблюдаемая трасса, если верна эта гипотеза». Шаблон = вектор средних `μₛ`
плюс ковариационная матрица `Qₛ`, то есть измеренное распределение утечки.

## Две адаптации, вынужденные тем, что `v = w·x`

**1. Шаблоны строятся по кампании, а не по одному весу.**
При фиксированном `w = 4` значение `v` пробегает только кратные четырём,
и для 12 гипотез из 14 шаблона бы просто не было. Кампания по весам 1…7
покрывает все 50 достижимых значений.

**2. POI выбираются среди точек, где побеждает нужный вес**, а не по максимуму SNR.
Хотспот кормит все шесть нейронов, поэтому глобальный максимум SNR может
принадлежать чужому нейрону (см. `05-poi-ambiguity.md`).

## Результат: работает

    POI = [5477, 8189, 6057]
    50 шаблонов, трасс на класс: мин 50, медиана 138

| ковариация | восстановлено | запас | стабильно с |
|---|---|---|---|
| полная | **+4 ✓** | 1777.3 | 29 трасс |
| диагональная | **+4 ✓** | 772.4 | 29 трасс |

Полная матрица даёт запас вдвое больше диагональной — подтверждает замечание
4.3.4 книги: учёт ковариации между точками добавляет информацию.

Для сравнения по числу трасс: алгоритм 2 (корреляция в одной точке) — 22 трассы.
То есть по скорости сходимости шаблоны здесь **не выиграли**, но дали
существенно больший отрыв от неверных гипотез.

# ⚠ Главное ограничение — прямо по теме диплома

**Шаблонная атака восстанавливает только тот вес, который варьировался
при профилировании.**

Кампания меняла только `L1_W[0][1]`. Проверка покрытия по нейронам:

| нейрон | вес | значений `v` при профилировании | покрытие гипотез |
|---|---|---|---|
| 0 | +4 | 50 | **100 %** — шаблоны строимы |
| 1 | −7 | 14 | 28 % — шаблонов нет |
| 2 | +5 | 14 | 28 % — шаблонов нет |
| 3 | +3 | 14 | 28 % — шаблонов нет |
| 4 | −4 | 14 | 28 % — шаблонов нет |
| 5 | −1 | 14 | 28 % — шаблонов нет |

В точках остальных нейронов вес всё время был один, `v` пробежало лишь 14
значений, и шаблона для чужой гипотезы не существует.

## Что из этого следует для вопроса «можно ли украсть модель»

Чтобы шаблонами достать `N` весов, при профилировании нужно **проварьировать
все `N`**. Это и есть требование книги «random keys» (P-DPA Step 2), только
в нейросетевой постановке цена его выше:

- слой 1 — 60 весов;
- слой 2 — 6 весов;
- плюс смещения и параметры переквантования.

И, что важнее объёма, это **сильное допущение об атакующем**: он должен уметь
записывать произвольные веса в клон-устройство. Не «иметь клон», а
«перепрошивать его под свои значения».

## Ближайший шаг, который это проверяет

Кампания меняла один вес. Если менять **весь столбец сразу** — на каждом
захвате свой набор `(w₀…w₅)` — то в точке каждого нейрона `v` тоже начнёт
варьироваться, и шаблоны станут строимы для всех шести.

Это тот же скрипт кампании, только патчится шесть значений вместо одного.
Прямая проверка: сколько весов столбца берут шаблоны, если профилирование
проведено правильно.

# Алгоритм 4b: весь столбец — 6 из 6

Скрипты: `campaign_column.py`, `alg4b_column_templates.py`

## Что изменили

Прошлая кампания меняла **один** вес, поэтому шаблоны строились только для
нулевого нейрона. Новая меняет **все шесть сразу**, по латинскому квадрату:

    захват k, нейрон o:  w = ((o + k) mod 7) + 1

За семь захватов каждый нейрон проходит все значения 1…7, а внутри одного
захвата у разных нейронов веса **разные** — это нужно, чтобы их точки утечки
можно было различить.

Время кампании: 238 с.

## Результат

| нейрон | истина | POI | восстановлено | запас |
|---|---|---|---|---|
| 0 | +4 | 4233 | +4 | 736 |
| 1 | −7 | 4813 | −7 | 21 092 |
| 2 | +5 | 5433 | +5 | 1 139 |
| 3 | +3 | 6053 | +3 | 33 841 |
| 4 | −4 | 6717 | −4 | 93 689 |
| 5 | −1 | 7334 | −1 | 4 528 |

**6 / 6.** Включая вес `+3`, который не давался ни одной другой модели
(корреляция гипотез `+3` и `+4` = 0.925, шаблонов = 0.975).

Сравнение на том же столбце:

| метод | весов |
|---|---|
| глобальный максимум (как у студента) | 1 / 6 |
| `wt(f32)`, корреляция | 3 / 6 |
| `μ(v)`, корреляция | 5 / 6 |
| **шаблоны, правильное профилирование** | **6 / 6** |

## ⚠ Ключевая деталь: точки назначаются по ПОРЯДКУ ИСПОЛНЕНИЯ

Это оказалось важнее самого различителя. Два подхода дали 4/6, и только третий — 6/6.

**Что не работает:**
- искать точку каждого нейрона независимо → две пары слиплись на расстоянии
  4 отсчётов, нейрон «восстановил» вес соседа (4/6);
- разнести точки, но назначать жадно по уверенности → соседние нейроны
  меняются местами (снова 4/6, но ломаются уже другие).

**Что работает:**
1. найти шесть точек с обязательным разносом (≥ 300 отсчётов);
2. **отсортировать их по времени и раздать нейронам по индексу.**

Прошивка считает `for (o = 0; o < 6; o++)`, значит умножение нейрона `o`
происходит **раньше** умножения нейрона `o+1`. Порядок во времени **и есть**
порядок нейронов. Найденные точки идут с шагом ~620 отсчётов — это длительность
обработки одного нейрона, и она подтверждает структуру.

То есть знание **структуры цикла** дало больше, чем любая модель утечки.

## Что это значит для темы диплома

Шаблонная атака при **корректно проведённом профилировании** восстанавливает
весь атакуемый столбец целиком. Ограничение «шаблоны берут только тот вес,
который варьировался» никуда не делось — просто теперь варьируются все шесть.

Цена: одна кампания из 7 перепрошивок на столбец. Для всего слоя 1 —
10 столбцов, то есть 70 перепрошивок и ~40 минут съёмки. Это **много,
но не запретительно**.

## Что остаётся непроверенным

- **Слой 2** — не атакован. Его входы это скрытые активации, их надо вычислять
  из уже восстановленного слоя 1.
- **Смещения и параметры переквантования** — не атакованы вообще.
- **Переносимость между устройствами.** И профилирование, и атака шли на
  **одной плате**. В реальной атаке профилируют на своём экземпляре, а атакуют
  чужой, и разброс между чипами — известная проблема шаблонных атак.
  Наш результат — **верхняя оценка**.
