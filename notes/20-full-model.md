# Модель целиком: смещение слоя 2, масштаб, и сравнение с оригиналом

## Смещение слоя 2 — восстановлено

Утекающая величина `acc2 + b2`, причём `acc2` уже известен точно (слой 1 плюс
`W2`). Одного профилирующего смещения мало — та же ловушка покрытия, что была
с весами: гипотеза сдвигает значение, а шаблон есть только для тех значений,
что реально произошли. Поэтому кампания из пяти прошивок, `b2 ∈ {−24, −12, 0,
12, 24}`, размазывающая диапазон.

Целевые трассы новые не понадобились: `sweep2` снят теми же векторами.

**`b2 = −1`**, устойчиво при 1…8 точках интереса и обоих порогах отбора.

    venv/bin/siphon capture-l2bias --from <слой1>/results.json \
        --out data/rebuilt_firmware/l2bias -n 3000

## Масштаб слоя 2 — НЕ восстановлен, и причина структурная

Пробовали три модели (`HW` логита, `HW` младшего байта, отдельный бит) —
все дают плоские 0.96…0.97 на любом `s2`. Нашли, что после `trigger_low`
трасса продолжается и на отсчёте ~11721 виден второй сильный пик: это
`simpleserial_put` передаёт байты результата. Побайтная модель там тоже не
сработала. Снятие гладкой части и поиск в остатке — истинное значение
оказалось на 820-м месте из 7979.

Причина не в трассах:

> Логит — **детерминированная функция** `pre = acc2 + b2`. Независимой
> вариации нет. Различать `s2` можно только по форме зависимости, а
> `pre` при `a ∈ 0…7` и наших весах лежит в −71…139, то есть даёт от силы
> 210 различных значений, у нас 86 с приличной статистикой.

По 86 точкам отличить быстро осциллирующие модели с шагом `s2` порядка 0.005
невозможно — задача недоопределена, любая высокочастотная модель ложится на
шум не хуже правильной. **Входное пространство последнего слоя само по себе
слишком мало.** Больше трасс тут не помогут.

Что осталось непробованным: побайтная атака на само умножение
`temp = acc·m0` — классический divide-and-conquer по байтам множителя.
Это отдельная работа, мы её не делали.

**Но на предсказания `s2` не влияет.** Переквантование монотонно и
положительно, поэтому знак логита определяется знаком `acc2 + b2`, который мы
воспроизводим. Для решения сети масштаб не нужен; он нужен только для
побайтно точного значения возвращаемого int32.

## Сравнение с оригиналом

50 000 случайных int8-входов, восстановленная модель собрана **только** из
наших прогонов, истина использована лишь для подсчёта совпадений.

### Параметры

| | восстановлено | примечание |
|---|---|---|
| веса слоя 1 | **60 / 60** | один (x9/n5) устойчиво не берётся, здесь угадан |
| смещения слоя 1 | 4 / 6 | n4 и n5 промахнулись на единицу |
| масштабы слоя 1 | 6 / 6 | как `s = m0/2^(31+n)` |
| веса слоя 2 | **6 / 6** | |
| смещение слоя 2 | **1 / 1** | |
| масштаб слоя 2 | — | не восстановлен, на решения не влияет |

### Поведение

| | |
|---|---|
| скрытый вектор совпал целиком | **99.246 %** |
| отдельные активации | **99.874 %** |
| `acc2 + b2` точно | **99.246 %** |
| **знак логита — решение сети** | **99.982 %** |

Расхождений по знаку: **9 из 50 000**. У всех девяти истинный `acc2 + b2` не
превышает 7 по модулю — то есть расходимся только там, где сама сеть стоит
вплотную к границе решения.

Медианное расхождение `acc2 + b2` — ноль, среднее 0.049 при диапазоне
−50…118.

## Точный расклад: это НЕ 100 %

Соблазн сказать «модель восстановлена полностью» велик, поэтому по пунктам.

**Совпадает точно:** все 66 весов (60 + 6), смещение слоя 2, смещения и
масштабы нейронов 0…3 первого слоя.

**Не совпадает:**

| нейрон | b наше | b истина | 1/s наше | 1/s истина | ошибка |
|---|---|---|---|---|---|
| 4 | 0 | −1 | 28.50 | 27.77 | 2.6 % |
| 5 | −2 | −3 | 24.25 | 23.86 | 1.6 % |

Плюс масштаб слоя 2 не восстановлен вовсе.

**Важная деталь:** у нейронов 4 и 5 ошиблись *и* смещение, *и* масштаб, причём
согласованно — подгонка разменяла одно на другое. Как функция активации наши
параметры расходятся с истинными на 12 значений `acc` из 1100 у нейрона 4 и на
3 из 1100 у нейрона 5.

Отсюда вывод, который стоит вынести отдельно:

> Пара `(b, s)` наблюдаема только через ступенчатую функцию, а разные пары
> задают почти одинаковую ступеньку. **Точные константы прошивки по трассам
> в принципе не восстановимы — восстановима функция, которую они задают.**

Для кражи модели этого достаточно. Для «побитового совпадения с прошивкой» —
нет, и обещать этого нельзя.

## Оговорка, обесценивающая 99.98 %: мишень почти вырождена

Мерили на случайных int8-входах. Оказалось:

- **91.1 %** активаций сидят в насыщении (0 или 7);
- среди 400 000 входов **нет ни одного**, где все шесть нейронов были бы в
  линейном режиме.

Сеть предыдущего студента работает практически как набор ступенек и скрытым
слоем почти не пользуется. Её решения устойчивы не потому, что мы хорошо
восстановили модель, а потому что их трудно сдвинуть.

Механизм нашей ошибки виден точно — она бьёт там, где нейрон стоит у порога:

| расстояние до порога | доля входов | скрытый вектор | решение |
|---|---|---|---|
| < 0.5 единицы | 1.8 % | **88.9 %** | 99.86 % |
| 0.5…1 | 1.7 % | **88.1 %** | 99.68 % |
| 1…2 | 3.4 % | 96.4 % | 99.96 % |
| > 5 | 31.9 % | **100 %** | **100 %** |

Вдали от порогов мы точны абсолютно; вблизи теряем каждый девятый скрытый
вектор. Сеть, которая реально решает нелинейную задачу, обязана держать
активации в промежуточном диапазоне — значит доля «опасных» входов у неё
кратно выше наших 3.5 %, и точность поехала бы с 99.2 % в сторону 89 %.

**Вывод: наша мишень — слабый стенд.** Заявлять «краденая модель работает как
оригинал» на почти вырожденной сети значит подставляться. Проверять надо на
сети, которая действительно считает.

## Что это значит для темы диплома

Ответ на вопрос «можно ли шаблонной атакой украсть модель» — **да**, и
измеренная цена такова:

- ~40 минут на плате для сети 10→6→1 (runbook в заметке 19);
- клон-устройство, в которое атакующий записывает свои параметры;
- та же физическая плата (перенос между чипами не проверялся ни разу).

Причём «украсть» здесь не метафора: краденая сеть принимает те же решения,
что оригинал, на 99.98 % входов, при том что два смещения из шести неточны,
а масштаб выходного слоя не восстановлен вовсе.

Но цифру 99.98 % нельзя подавать без оговорки выше: она получена на сети,
которая почти не пользуется скрытым слоем. Следующие два шага — собрать
автоматический извлекатель и прогнать его на сети той же архитектуры с
другими весами, а затем на сети, обученной решать настоящую нелинейную
задачу.
