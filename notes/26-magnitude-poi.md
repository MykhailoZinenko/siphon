# POI по магнитуде: почему сеть XOR давала 40/60 и как это чинится

## Симптом

Обученная сеть Фазы 2 (XOR знаков, активные веса ±2) восстанавливалась на
слое 1 как **40/60**: нули верны, знаки верны, **магнитуды случайны**
(вместо +2 выходило +5, +6). Эталонная сеть seed-4242 при этом даёт 60/60.

## Корень (доказан на кэше, без платы)

POI выбирается по **SNR по v = w·x**: межклассовая дисперсия / внутриклассовая.
Утечка, кодирующая только **знак v**, даёт два узких далёких кластера —
максимум SNR — но **нуль информации о магнитуде**. Кривые «среднее в точке от v»
это показывают прямо:

- phase2, нейрон 2: любое v<0 → −0.040, любое v>0 → −0.005, плоско внутри знака.
- seed-4242, нейрон 3: плавно едет с магнитудой (0.132 → 0.113).

У seed-4242 веса крупные и разнообразные, поэтому максимум SNR попадает на
градуированную по магнитуде точку; у XOR-сети веса ±2 при входах ±7 дают малое
|v|≤14, и максимум SNR садится на точку «только знак». Отсюда ровно эта картина
40/60. Профилирование у обеих сетей одинаковое (прошиваются веса 0..7), так что
различие целиком в атакующих трассах — не баг кода, а слепое пятно критерия.

## Починка №1 — критерий POI (только анализ, без платы)

Считать SNR по **|v| внутри каждого знака**: это поощряет точки, градуированные
по магнитуде, а знак всё равно берётся из шаблонов. `siphon/src/siphon/poi.py`,
`leak_profile`. Проверено на кэше:

| | phase2 | seed-4242 |
|---|---|---|
| старый SNR по v | 40/60 | 60/60 |
| **SNR по |v| внутри знака** | **50/60** | **60/60** (те же POI — регрессии нет) |

Регрессия закрыта тестом `siphon/tests/test_poi_magnitude.py`. По нейронам
phase2: n0,n1,n2,n5 → 10/10, n3 → 8, **n4 → 2** (у n4 нет градиентной точки
нигде: v-SNR@POI = 3.6).

## Починка №2 — широкие входы (нужна плата)

Входы слоя 1 — **int8 (−128..127)**, а не 3 бита (3 бита — это активации 0..7).
Значит `NONZERO_INPUTS = ±1..7` — свободный выбор, не ограничение. Если гнать
вход до ±127, то для веса 2 получается v = ±254 — в зоне, где утечка несёт
магнитуду. `SIPHON_INPUTS` в `capture.py` переопределяет набор (магнитуды
зеркалятся в минус). Конфиги: `siphon/configs/phase2_wide/`.

Перезахват кампании и атаки на текущей (phase2) прошивке:

```bash
export SIPHON_INPUTS="16,32,48,64,80,96,112,127"
venv/bin/siphon capture-campaign -c siphon/configs/phase2_wide/column1.yaml -n 1000
venv/bin/siphon capture-attack   -c siphon/configs/phase2_wide -n 1000
```

Оба шага читают SIPHON_INPUTS, поэтому шаблоны и атака идут на одном наборе (это
обязательно для покрытия). Для слоя 2 этот приём НЕ доступен: его входы —
активации 0..7.

## Результат на плате (широкие входы ±16..±127)

**60/60.** Все веса слоя 1 восстановлены точно, включая n4 (было 2/10) и
активные столбцы: n2 [2,−2], n3 [2,2], n4 [−2,−2], n5 [−2,2], n0/n1 нули.
Цепочка подтверждена целиком: 40/60 (старый SNR) → 50/60 (POI по магнитуде,
только анализ) → **60/60** (POI по магнитуде + широкие входы). Малый вес делал
v = w·x слишком маленьким, чтобы утекала магнитуда; широкий вход выводит v в
градуированную зону.

## Слой 1 закрыт полностью, W1 сохранён

`siphon layer -c siphon/configs/phase2_wide` даёт 60/60 и пишет результат в
`siphon/runs/20260921-165249-layer-1-weights/results.json` — это верный W1 для
всех дальнейших шагов Фазы 2.

## Смещения/масштаб: код готов, осталась плата

Истинные L1_B Фазы 2 = `{−9, 0, −61, −63, −63, −59}` — четыре ниже −40, поэтому
старая сетка `bias_grid = ±40` физически не могла их представить. Расширено до
`±80` в `extract.py` и `cli.py` (тесты проходят). Прежний свип в
`data/phase2/sweep` собран из НЕВЕРНОГО (40/60) W1: crafted-входы не проводят
реальные нейроны по всем 8 классам активации, поэтому нужен пере-свип с верным
W1. `craft` детерминирован по seed, так что свип и профиль клона делят один набор
входов (это проверяет сам `activation`). Порядок (шаги с платой пишут в НОВЫЕ
директории — старые собраны на неверном W1):

```bash
R=siphon/runs/20260921-165249-layer-1-weights/results.json
venv/bin/siphon capture-sweep      --from $R --out siphon/data/phase2/sweep2       # плата
venv/bin/siphon capture-activation --from $R --out siphon/data/phase2/act_profile2 # плата
venv/bin/siphon activation --from $R --profile siphon/data/phase2/act_profile2 \
                                     --target  siphon/data/phase2/sweep2
```

## Смещения/масштаб: две вырожденности, обе измерены и починены

Даже с расширенной сеткой ±80 фит `(b, s)` садился на границы сетки
(`b1 = [-80,-80,24,-54,-37,-80]`, `1/s` у краёв). Две причины, обе специфичны
для сети, которая ПОЛЬЗУЕТСЯ скрытым слоём:

1. **Знак-зеркальные пары весов рушат свип.** У XOR-сети n4 = −n3, n5 = −n2
   (n3=2(x0+x1), n4=−2(x0+x1); n2=2(x0−x1), n5=−2(x0−x1)). `craft` держит acc
   ВСЕХ нейронов в одном окне; для ± пары пересечение асимметричного [−60,420]
   схлопывается в **[−60,60]** — целиком ниже первого порога активации (~76),
   так что все нейроны сидят в классе 0, лестницы нет, `(b,s)` не определён.
   Починка: **симметричный свип** (`extract --span=-350,350`): каждый нейрон
   получает и лестницу (на своём знаке acc), и насыщение. Проверено: при ±350
   худший класс ≥67 трасс на всех активных нейронах, при ±60,420 — 0.

2. **Тонкие классы дисквалифицировали ИСТИНУ.** `_distances` ставил `inf`
   классу с числом трасс < ширина+3. Клон (1/s=50) на краю свипа даёт классу 7
   лишь 7–12 трасс → при 20 POI его шаблон = inf. Истинный `(b,s)` заводит часть
   трасс в класс 7 → суммарная стоимость inf → истина выбывает, а побеждает
   грубая лестница (большое 1/s), которая класс 7 не предсказывает. Починка:
   **объединённая (pooled) ковариация** — одна на все классы, оценивается по всем
   внутриклассовым остаткам (3000 трасс), поэтому оценима всегда; её log-det
   общий для классов и выпадает из argmin. Плюс **окно POI только по чтениям
   hidden_q слоём 2** (L2_READS), без окна аккумулятора: точки аккумулятора
   проходят фильтр «утечки a», но несут сырой acc и валят n3.

Итог (реальная команда `siphon activation` на данных с платы): 1/s и b —
n2 (23.2, −60), n3 (26.95, −63 точно), n4 (25.45, −65), n5 (33.3, −59 точно);
n0/n1 мёртвые (нулевые веса, активация всегда 0 — фит для них мусорный, но
безвредный). **Согласие активаций с истиной на 20k случайных int8: 98.6–100%
по всем нейронам** — то, что нужно слою 2. Гистограммы классов подтверждают:
нейроны расходятся по 0..7, а не сидят в насыщении (в отличие от случайных
мишеней с ~91% насыщения) — это и есть цель Фазы 2.

Слой 2: мёртвые нейроны n0/n1 нельзя изолировать (активация всегда 0), поэтому
`layer2.recover` помечает их как невосстановимые (вес 0, покрытие 0%) вместо
падения; их истинный L2_W и так 0.

## Полная цепочка на плате пройдена — модель украдена (Фаза 2)

`siphon extract ... --span=-350,350`, затем `siphon phase2`:

| | результат |
|---|---|
| веса слоя 1 | **60/60** |
| смещения слоя 1 точно | 2/6 (но скрытый вектор 97.8%) |
| веса слоя 2 | **5/6** (промах только a3: −1 вместо −2) |
| смещение слоя 2 | точно |
| точность задачи, оригинал | 98.3% |
| **точность задачи, восстановленная сеть** | **95.3%** |
| согласие решений на задаче | 95.3% |

Ответ на вопрос диплома: **шаблонная атака крадёт РАБОЧУЮ модель.** Украденная
сеть решает XOR знаков на 95.3% против 98.3% оригинала (линейная модель — 50%),
всё восстановлено из трасс питания. Это ЧЕСТНАЯ мишень — та, что пользуется
скрытым слоём, а не вырожденная с ~91% насыщения, где 99.98% давались даром.
Согласие на задаче (95.3%) выше, чем на равномерном int8 (92.7%): на
распределении задачи решение ВЫХОДА уверенно, хотя скрытые нейроны у своих
порогов. Остаточные 3 п.п. — ошибка атаки: промах a3 слоя 2 (мало уровней
активации у n3) и два компенсирующих смещения слоя 1 (n2, n4).
