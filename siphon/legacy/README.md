# Легаси: алгоритмы 1–3

Здесь лежат реализации первых трёх методов из раздела 4.3 учебника.
Они **не заменены** пакетом `src` — тот делает только шаблонную атаку (4.3.2.3).
Все результаты, описанные в `../../notes/`, получены именно этим кодом,
и он оставлен запускаемым, чтобы было с чем сверяться.

Данные общие и лежат в `../data/` — дублировать 9.5 ГБ по папкам смысла нет.
Пути разрешает `paths.py`.

| папка | что внутри | итог |
|---|---|---|
| `alg1/` | непрофилированная DPA + оригинальные скрипты студента | identity-модель вырождается, HW восстанавливает 1 вес |
| `alg2/` | профилированная DPA, SNR и POI | 22 трассы; обнаружено, что один POI ≠ один вес |
| `alg3/` | стохастическая модель + кампания по одному весу | не работает: утечка не линейна по битам |
| `alg3_modified/` | попытка починить пулингом по нескольким точкам | не сработала: модели в разных точках различаются |

## Запуск

    venv/bin/python siphon/legacy/alg1/nonprofiled_dpa.py
    venv/bin/python siphon/legacy/alg2/column_recovery.py
    venv/bin/python siphon/legacy/alg3/stochastic_campaign.py

Графики каждый пишет в свою `graphs/`.
